# Categories and why

Defined in `../rules.json`; the first matching category wins.

| id | Folder | Patterns | Why there |
|---|---|---|---|
| skill | `.claude/skills/<name>/` | `SKILL.md` | Claude Code discovers skills only in this folder. The skill's own `scripts/` and `references/` stay inside. |
| paper-source | `papers/source/` | `*.pdf` | The paper itself. |
| paper-transcription | `papers/audit/transcriptions/` | `scan_table*.json`, `*_pass2.json`, `transcription*.json` | Output of the paper-visual-audit skill: tables read twice from the scan. |
| paper-audit | `papers/audit/` | `checks_*.md`, `inventory_*.json`, `audit_report*.md` | Reports and check results about the paper itself. |
| paper-verification | `papers/verification/` | `paper_check*.md`, `ref_simulator*.py`, `*sensitivity*.py`, `*_vs_paper*.md` | Material that checks **our** website and skills against the paper. |
| global-config | `config/` | `site-config.*`, `*.config.json`, `*.config.js`, `config.json`, `settings.json`, `*.toml` | Site-wide settings: one place, everything else is generated from it. |
| dev-tool | `_dev/` | `build*.py`, `template*.html`, `*.template.html` | Tools for building the site; the folder name starts with `_` so GitHub Pages does not publish it. |
| site-style / site-script / site-icon | `assets/css/`, `assets/js/`, `assets/icons/` | `*.css`, `*.js`, `*.svg`, `*.ico` | Files the pages load. |
| site-page | project root | `*.html` | A page's URL is its file name; moving it would break links and bookmarks. |

## Pinned (never moved)
| File | Why it must stay |
|---|---|
| `README.md` (any folder), `.gitignore`, `.nojekyll`, `CLAUDE.md` | Conventions of git, GitHub and Claude Code. |
| `manifest.json`, `sitemap.xml` | Generated by `_dev/build.py` at the root; browsers and search engines expect them there. |
| `sw.js` | A service worker only controls the folder it is served from, so it must be at the root. |
| `.githooks/*`, `.claude/settings*.json` | Read by git and Claude Code from these paths. |

## Containers
Files inside `assets/`, `papers/`, `config/`, `_dev/`, `.claude/skills/` or `.githooks/` that match no rule are accepted as placed (for example the audit images under `papers/audit/images/`). A file outside every container that matches no rule is UNCLASSIFIED.
