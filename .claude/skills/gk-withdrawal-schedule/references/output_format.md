# 輸出格式

依序三個部分（腳本會全部印出；原樣呈現，不要修改）。

1. **規則門檻**：IWR、上護欄（保本規則觸發點）、下護欄（繁榮規則觸發點）、保本規則啟用的年份、使用的檢定順序、通膨規則。
2. **逐年表**，欄位如下：

| 欄位 | 意義 |
|---|---|
| 年份 / 年齡 | 年份（有 `--start-age` 時加年齡） |
| 年初資產 | 年初資產 |
| 前年通膨率 | 前一年通膨率（第 1 年空白） |
| 試算提領率 | 前一年提領 × (1 + 前一年通膨率) ÷ 年初資產 |
| 觸發規則 | 初始 / 正常調整 / 凍結 / 保本 −10% / 繁榮 +10%（`freeze` 順序下，同一年可能是 凍結 + 保本）/ 資金用完 / 資金已用完 |
| 當年實際提領 | 套用規則後的最終提領 |
| 實際提領率 | 最終提領 ÷ 年初資產 |
| 購買力 | 最終提領 ÷ 單純隨通膨調整的計畫提領（100% = 生活水準相同） |
| 當年報酬 | 當年投資組合總報酬 |
| 年底資產 | （年初 − 提領）× (1 + 報酬) |

3. **摘要**：下調、上調、凍結的次數；成功，或資金用完的年份；期末資產；購買力（各年平均與最後一年，只計成功的路徑）；總提領金額。

向使用者說明時（繁體中文）：每條規則用一句話講清楚年份、規則與原因，例如「第 2 年前一年虧損 15%，含通膨的提領率 6.32% 高於初始 5%，所以先凍結；凍結後的提領率 5.57%…」。不要把單一路徑說成機率。
